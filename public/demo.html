Universal Amount Standard

Standalone API demo · release 0.0.2

Canonical digits

Canonical values are decimal strings with eight fractional places.

Exact arithmetic

Exact arithmetic is a core UAS guarantee for totals, nested modifiers, fees, balances, payouts, and allocations. This endpoint is included as a demonstration and conformance check.

Explicit conversion

Rates are supplied explicitly in 0.0.2; the API does not claim they are live.

Locale formatting

Formatting is derived presentation. The canonical amount remains unchanged.

Choose a locale or currency to see the derived display update.
